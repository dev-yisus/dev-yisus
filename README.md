### About Me

Passionate **Software & Data Solutions Engineer** specialized in reverse-engineering data architectures, business intelligence automation, and enterprise microservices.

- Creator of **[pbip-forge](https://github.com/dev-yisus/pbip-forge)**: Programmatic generation engine for Microsoft Fabric and Power BI Developer Mode (`.pbip` / TMDL).
- Designing resilient distributed systems with **Java 17 (Spring Boot 3 / Cloud)**, **.NET 8 (C#)**, and **Python**.
- Engineering scalable relational models, automated DAX metrics, and Kimball Data Warehouses.
- Building autonomous AI agent workflows and developer tooling.
